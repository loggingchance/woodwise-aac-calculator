Set up Local FVS for WoodWise AAC

WoodWise can run the USDA Forest Service Forest Vegetation Simulator on your own computer through a small local service at http://127.0.0.1:8787.

Quick Version

  1. Install the USDA Forest Service FVS Complete Package for Windows.
  2. Start the WoodWise local FVS service on your computer.
  3. Open WoodWise AAC and click Use Local FVS.
  4. Confirm the FVS service URL is http://127.0.0.1:8787.
  5. Load or edit strata, then click Run FVS analysis.

Windows Setup

  1. Download the official USDA Forest Service FVS Complete Package.
  2. Run the installer and keep the default installation choices unless your organization requires a different folder.
  3. After installation, confirm the Northeast variant is present. WoodWise AAC currently expects Northeast FVS, usually named FVSne.exe.
  4. Start the WoodWise local FVS service. The service looks for FVS in common install folders and can also use AAC_FVS_NE_PATH when a custom path is needed.
  5. Leave the local service window running while using WoodWise AAC.
  6. In WoodWise AAC, click Use Local FVS, then click Run FVS analysis.

macOS Setup

USDA does not currently provide the same simple official macOS installer experience as the Windows Complete Package. For macOS, the technically supportable path is to build FVS from USDA source code or use a packaged WoodWise connector after one has been verified.

  1. Use a Windows computer for the easiest setup today, or run Windows in a supported virtual environment.
  2. If you are comfortable building scientific software, start from the official FVS source-code project linked by USDA.
  3. After a working Northeast FVS executable exists, configure the WoodWise local service to point at that executable.

Browser Permission Prompt

WoodWise runs at a public HTTPS address, but your local FVS service runs on your own computer. Some browsers may ask before allowing the site to reach 127.0.0.1. That prompt is expected. The connector should stay bound to 127.0.0.1 and should not be exposed to the public internet.
